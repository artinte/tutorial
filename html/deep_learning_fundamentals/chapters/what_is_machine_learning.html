什么是机器学习

机器学习是人工智能的重要组成部分。 它让计算机能够从数据中发现规律， 并利用已经学习到的规律， 对新的数据进行预测、分类或决策。

1-1 基础概念 约 10 分钟
1.1.1

机器学习到底在做什么？

如果我们直接告诉计算机一条条明确的规则， 这属于传统的程序设计。 例如，我们可以写出这样的规则：

传统程序设计

如果一个人的年龄大于等于 18 岁， 就判断为成年人；否则判断为未成年人。

这种方式的特点是： 人先定义规则，计算机按照规则执行。

但是现实世界中存在大量非常复杂的问题。 比如判断一张图片中是不是一只猫、 判断一封邮件是不是垃圾邮件， 或者根据历史数据预测未来结果。

对这些问题，我们很难提前写出一套完整而准确的规则。 这时就可以让计算机从大量数据中自己寻找规律。

机器学习

不再要求程序员把所有判断规则全部写出来， 而是给模型提供数据和对应的信息， 让模型通过学习得到一个能够处理新数据的规律。

1.1.2

从“写规则”到“学习规则”

可以通过一个简单的例子理解两种方式的区别。

传统程序

假设我们希望判断一封邮件是不是垃圾邮件。 传统方法可能会人为定义很多规则：

  • 如果邮件包含大量促销词汇，增加垃圾邮件评分。
  • 如果邮件包含大量链接，增加垃圾邮件评分。
  • 如果发件人地址可疑，增加垃圾邮件评分。
  • 如果评分超过某个阈值，就判断为垃圾邮件。

问题在于，垃圾邮件发送者也会不断改变策略。 固定规则很容易逐渐失效。

机器学习

如果我们拥有大量已经标记好的邮件， 就可以把这些数据交给机器学习算法。

模型会从这些数据中寻找： 哪些词语、结构、发送行为和其他特征， 与“垃圾邮件”这个结果存在较强关系。

学习完成之后， 当一封新的邮件出现时， 模型就可以根据已经学习到的规律进行判断。

1.1.3

机器学习的基本组成

一个典型的机器学习问题通常可以拆成几个重要组成部分。

01 · DATA

数据

用于描述现实世界中的对象、 行为和现象，是模型学习的基础。

02 · MODEL

模型

用于表示数据之间规律的数学结构， 是机器学习系统的核心。

03 · LEARNING

学习

通过算法不断调整模型， 让模型逐渐能够更好地解释数据。

1.1.4

什么是特征？

在很多传统机器学习任务中， 我们需要先从原始数据中提取能够描述对象的特征。

例如，我们希望根据房屋信息预测房价。 一套房子可能拥有以下特征：

  • 房屋面积
  • 房间数量
  • 建造年份
  • 距离地铁的距离
  • 所在区域

这些能够被模型使用的信息， 就可以称为 特征（Feature）。

模型通过分析这些特征与目标结果之间的关系， 学习如何进行预测。

1.1.5

什么是标签？

在监督学习中， 数据通常不仅包含输入特征， 还包含一个我们希望模型预测的目标结果。

这个目标结果通常称为 标签（Label）。

房屋面积 房间数量 房龄 房价
90㎡ 3 8 年 420 万
120㎡ 4 5 年 580 万
75㎡ 2 12 年 330 万

在这个例子中， 房屋面积、房间数量和房龄可以作为输入特征， 而房价就是模型需要学习预测的标签。

1.1.6

模型是如何学习的？

机器学习并不是简单地把数据“记住”。 模型真正需要学习的是： 输入与目标之间的关系。

例如，我们可以把房屋特征表示为：

x = [面积，房间数量，房龄]

模型接收到这些输入后， 输出一个预测值：

ŷ = f(x)

其中， x 表示输入特征， f 表示模型， ŷ 表示模型预测得到的结果。

如果预测结果与真实结果存在差距， 我们就需要通过某种方式衡量这个差距， 并根据差距调整模型。

这就引出了后面非常重要的概念： 损失函数（Loss Function） 。

1.1.7

一个最简单的机器学习模型

在线性回归中， 我们可以使用一个非常简单的数学模型：

ŷ = wx + b

其中：

  • x：输入特征
  • w：模型参数，也可以理解为权重
  • b：偏置
  • ŷ：模型预测结果

机器学习的一个核心过程， 就是寻找合适的 w 和 b， 使模型的预测结果尽可能接近真实数据。

Python · 一个最简单的模型表达 
def predict(x, w, b):
    return w * x + b
1.1.8

训练数据与测试数据

如果模型只在已经见过的数据上表现很好， 并不能说明它真的学会了规律。

一个机器学习系统通常需要把数据划分成不同部分。

  • 训练集（Training Set） ：用于训练模型。
  • 验证集（Validation Set） ：用于调整模型和超参数。
  • 测试集（Test Set） ：用于最终评估模型在新数据上的表现。
为什么不能只看训练数据？

因为模型可能只是把训练数据记得非常好， 却没有真正学习到能够推广到新数据的规律。 这种问题称为过拟合（Overfitting）。

1.1.9

机器学习的三种主要类型

根据学习数据和任务形式， 机器学习通常可以分为几类。

监督学习

数据中存在明确的输入和目标结果， 模型通过这些带标签的数据学习。 分类和回归是监督学习中非常常见的任务。

无监督学习

数据没有明确的标签， 模型需要自己发现数据内部的结构。 聚类就是一个典型例子。

强化学习

模型通过与环境交互， 根据行动得到的奖励或惩罚， 逐渐学习更好的决策策略。

1.1.10

机器学习与深度学习的关系

深度学习并不是与机器学习完全不同的另一套技术。

更准确地说， 深度学习是机器学习中的一个重要分支。

一个简单的关系

人工智能 → 机器学习 → 深度学习

传统机器学习经常依赖人工设计的特征。 深度学习则可以利用多层神经网络， 从原始数据中自动学习越来越复杂的表示。

例如，在图像任务中， 传统机器学习可能需要人工设计边缘、 纹理等特征。 深度神经网络则可以通过训练， 从像素数据中逐层学习这些表示。

本节总结

这一节需要掌握什么？

  • 机器学习的核心是让计算机从数据中学习规律。
  • 特征描述输入数据，标签描述希望预测的目标。
  • 模型通过学习参数建立输入与输出之间的关系。
  • 训练数据用于学习，测试数据用于评价泛化能力。
  • 监督学习、无监督学习和强化学习是常见的学习范式。
  • 深度学习是机器学习的重要分支。
